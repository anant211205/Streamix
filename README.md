# Streamix

**Streamix** is a global communication platform that helps users connect with people around the world through **chat**, **video calls**, and **language learning**. Whether you're looking to improve your speaking skills, explore new cultures, or just make friends, Streamix makes it easy to communicate and grow together.

---

##  Features

- **Real-Time Chat** – Seamless messaging with users across the world.
- **High-Quality Video Calls** – Face-to-face communication powered by WebRTC.
- **Language Exchange** – Learn and practice new languages with native speakers.
- **Global Community** – Connect based on interests, languages, and location.
- **Secure and Private** – Conversations are encrypted and safe.

---

## Tech Stack

- **Frontend**: React / Tailwind CSS
- **Backend**: Node.js / Express 
- **Database**: MongoDB 
- **Authentication**: JWT / OAuth 
- **Real-Time Communication**: WebRTC / Socket.IO via Stream
- **Deployment**: Render
